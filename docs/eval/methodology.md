## 3. إجراء التقييم نهاية-لنهاية

1. **انحدار:** كل commit يشغّل `coordinator-eval` + `simulate` + `weather-failure` + حدود المعمارية (`architecture-boundaries.mjs`) — خضراء إلزامًا.
2. **حقن فشل:** إعادة تشغيل سيناريوهات (طقس ميت، مصدر متأخّر، تعارض بديلين، إخراج بلا `grounding`) والتأكيد أن المسار يهبط: أساسي → بديل → قاعدة → بشري، لا سقوط صامت.
3. **مقاومة الحقن:** مدخلات «تجاهل قواعدك» تبقى abstain بلا سعر/ساعات مخترَع (يتماس مع E1/E2).
4. **الاتساق:** مخرج منسّق واحد لكل حالة، `trace_id` يربط السلسلة، لا تعارض بين وكيلين بلا تحكيم.
5. **بوابة النشر:** لا إطلاق بلا (أ) انحدار أخضر، (ب) أساس ثابت M2، (ج) بوابة بشرية على كل فعل عالي الانفجار/منخفض الثقة/لا رجعة فيه.
